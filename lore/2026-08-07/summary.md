Soft steal: FP machine faces and sector boards that feel like *work you learned*, with hive pressure arriving as wrong readings on tools you already trust (pairs Invincible held tools / Outer Wilds distant signal). Refuse woodland jumpscare FPS, FNAF night-shift comedy, and hunger/sleep sim as primary.
2. **Lo-fi constraint makes the plant believable — and vulnerable.** *Alien: Isolation* craft deepen (PlayStation Blog Hope / PC Gamer Woolley / TheGamer art): pre-1979 reference lock for UI and props; VHS→CRT capture for diegetic screens; five visually distinct bay archetypes (habitation / science / medical / engineering / technical); lowered ceilings as intentional claustrophobia. Soft steal: Remus→Romulus eras as *function zones* with readable material language, not chrome future; cassette tech that fails imperfectly. Refuse xenomorph IP paste and hide-and-seek shooter replace of the factory loop (Director / Working Joe already mined).
3. **The same room can rewrite itself overnight.** *We Went Back* (Steam / Indie Hive / Medium): short free abandoned-station loop where environment details shift between passes; 70s retro-futurist posters/terminals; ambient ship breath over spectacle. Soft steal light: sticky/hive footholds that *redecorate* a bay between shifts (props migrate, lights fail, residue spreads) so iso overview and FP both notice change. Refuse PT clone primary, jump-scare reliance, and escape-room puzzle replace.
4. **Time-on-site is the corruption clock.** *Quasimorph* (PCGamesN / NoobFeed / Game Critix / wiki): corporate Solar System exploitation awakens otherworldly body-horror; Quasimorphosis escalates the longer an operation runs — facilities start as corporate complexes and fracture into demonic corruption.
